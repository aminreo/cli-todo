# Todo app
simple CLI version

# Usage
after cloning this repo and `cd` into the directory
```java
javac TodoApp.java 
java TodoApp "task1" "task2"
```
output
```console
Task added: task1
Task added: task2
```
# Commands
* list
```java
list
```
output
```console
[task1, task2]
```
* exit
```java
exit
```
output
```console
Closing app...
```
Closes the app
